# MATH 221 Group 3: MATLAB scripts

MATLAB code for our MATH 221 Numerical Analysis group project at Prince Sultan University.
Exercises are from Burden and Faires, *Numerical Analysis*, 9th edition.

| Script | Exercise | Uses |
|---|---|---|
| `ex2_3_13.m` | Section 2.3, Ex. 13: Newton and Secant | `newton.m` |
| `ex2_3_3a.m` | Section 2.3, Ex. 3(a) (extra, for visualization) | |
| `ex3_2_11.m` | Section 3.2, Ex. 11: Neville's method | `neville.m` |

[Open this repository in MATLAB Online](https://matlab.mathworks.com/open/github/v1?repo=AljawharaAlruzuq/math221-matlab) (needs a free MathWorks account), then type a script name in the Command Window.
